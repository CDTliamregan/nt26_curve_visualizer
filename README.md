# NT2.6 Curve Visualizer (moved)

**This tool moved to https://productiontoolz.com/tools/led-curve/ on Nov 16, 2026.** It is now the LED Curve Visualizer on Production Toolz, and that is the only copy being maintained.

This repository is kept only so old links keep working. Its page, https://cdtliamregan.github.io/nt26_curve_visualizer/, now shows a short "this tool has moved" notice and forwards to the new address.

## Corrected NT2.6 limits

The new version also corrects the NT2.6 limits: concave to 10°, convex to 7.5°. The old page had them the other way round (convex to 10°, concave to 7.5°), so do not plan a wall from the old version.

Source, checked on Nov 16, 2026: Absen publishes the NT2.6 curve range as -7.5° to +10°, and page 7 of Absen's NT Series user manual says -7.5 is convex and +10 is concave.

## The old tool

The original single-page tool is still in this repository's history. Its last version is [`index.html` at commit `4f83216`](https://github.com/CDTliamregan/nt26_curve_visualizer/blob/4f83216b2efb558017c14c2e1dc1f5adc9377dd6/index.html). It is no longer maintained.
